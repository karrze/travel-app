# Backlog MVP

## Epic 1 – Zaplanowanie podróży

### Task 1.1 – Wybór miejsca podróży

#### User Stories

* Jako użytkownik chcę wskazać miejsce podróży, aby otrzymać rekomendacje dopasowane do miejsca, do którego jadę.
* Jako użytkownik chcę wyszukać miejsce podróży z listy podpowiedzi, aby szybciej rozpocząć planowanie.
* Jako użytkownik chcę zmienić wybrane miejsce podróży, aby poprawić błędnie wprowadzone informacje.

### Task 1.2 – Określenie terminu wyjazdu

#### User Stories

* Jako użytkownik chcę wskazać datę rozpoczęcia podróży, aby aplikacja mogła przygotować plan wyjazdu.
* Jako użytkownik chcę wskazać datę zakończenia podróży, aby otrzymać stylizacje na każdy dzień pobytu.
* Jako użytkownik chcę zmienić termin podróży, aby dostosować plan do nowych okoliczności.

### Task 1.3 – Określenie długości pobytu

#### User Stories

* Jako użytkownik chcę zobaczyć liczbę dni podróży, aby upewnić się, że plan został przygotowany poprawnie.
* Jako użytkownik chcę, aby liczba dni została wyliczona automatycznie na podstawie dat wyjazdu i powrotu.

### Task 1.4 – Wybór rodzaju bagażu

#### User Stories

* Jako użytkownik chcę określić rodzaj bagażu, aby otrzymać listę rzeczy dopasowaną do jego pojemności.
* Jako użytkownik chcę zmienić rodzaj bagażu, aby porównać różne warianty pakowania.
* Jako użytkownik chcę otrzymać informację, jeśli wybrane rzeczy mogą nie zmieścić się do mojego bagażu.

### Task 1.5 – Określenie planowanych aktywności

#### User Stories

* Jako użytkownik chcę wskazać aktywności planowane podczas podróży, aby rekomendacje garderoby były dopasowane do moich planów.
* Jako użytkownik chcę, aby wskazane aktywności zostały uwzględnione podczas generowania stylizacji.

### Task 1.6 – Zatwierdzenie planu podróży

#### User Stories

* Jako użytkownik chcę zobaczyć podsumowanie planu podróży przed przejściem do kolejnego etapu.
* Jako użytkownik chcę zobaczyć w podsumowaniu miejsce podróży, termin, długość pobytu, rodzaj bagażu oraz planowane aktywności.
* Jako użytkownik chcę wrócić do wcześniejszych kroków i poprawić dane.
* Jako użytkownik chcę zatwierdzić plan podróży, aby rozpocząć dobór garderoby.

## Epic 2 – Digitalizacja garderoby

### Task 2.1 – Dodanie zdjęć ubrań

#### User Stories

* Jako użytkownik chcę dodać zdjęcia ubrań.
* Jako użytkownik chcę dodać kilka ubrań na jednym zdjęciu.
* Jako użytkownik chcę zrobić zdjęcie aparatem lub wybrać je z galerii.

### Task 2.2 – Skanowanie kilku ubrań jednocześnie

#### User Stories

* Jako użytkownik chcę zeskanować kilka ubrań jednocześnie.
* Jako użytkownik chcę zeskanować całą kategorię ubrań jednym zdjęciem.

### Task 2.3 – Automatyczne rozpoznanie ubrań

#### User Stories

* Jako użytkownik chcę automatycznie rozpoznać dodane ubrania.
* Jako użytkownik chcę automatycznie przypisać kategorię ubrania.
* Jako użytkownik chcę automatycznie rozpoznać kolor ubrania.

### Task 2.4 – Weryfikacja rozpoznanych elementów

#### User Stories

* Jako użytkownik chcę zweryfikować rozpoznane informacje.
* Jako użytkownik chcę zaakceptować poprawnie rozpoznane ubrania.

### Task 2.5 – Edycja błędnie rozpoznanych informacji

#### User Stories

* Jako użytkownik chcę poprawić kategorię ubrania.
* Jako użytkownik chcę poprawić kolor ubrania.
* Jako użytkownik chcę poprawić pozostałe informacje o ubraniu.

### Task 2.6 – Usuwanie ubrań

#### User Stories

* Jako użytkownik chcę usunąć błędnie rozpoznane ubranie.
* Jako użytkownik chcę usunąć wcześniej zaakceptowane ubranie, jeśli nie chcę go uwzględniać w mojej garderobie.

## Epic 3 – Dobór garderoby do podróży

### Task 3.1 – Analiza warunków pogodowych

#### User Stories

* Jako użytkownik chcę uwzględnić prognozę pogody.
* Jako użytkownik chcę zobaczyć pogodę na każdy dzień podróży.
* Jako użytkownik chcę otrzymać informację, jeśli szczegółowa prognoza pogody dla terminu mojej podróży nie jest dostępna.

### Task 3.2 – Analiza planowanych aktywności

#### User Stories

* Jako użytkownik chcę uwzględnić planowane aktywności.
* Jako użytkownik chcę otrzymać rekomendacje dopasowane do aktywności.

### Task 3.3 – Analiza ograniczeń bagażu

#### User Stories

* Jako użytkownik chcę uwzględnić pojemność bagażu.
* Jako użytkownik chcę otrzymać rekomendacje dopasowane do wybranego bagażu.

### Task 3.4 – Analiza zachowań i cech użytkownika

#### User Stories

* Jako użytkownik chcę określić swoje cechy mające wpływ na ponowne wykorzystanie ubrań, np. szybkie brudzenie ubrań.
* Jako użytkownik chcę określić informacje dotyczące swojej fizjologii mające wpływ na dobór garderoby, np. pocenie się.
* Jako użytkownik chcę, aby podane informacje zostały uwzględnione podczas przygotowywania rekomendacji garderoby.

### Task 3.5 – Wybór odpowiednich ubrań

#### User Stories

* Jako użytkownik chcę otrzymać rekomendowane ubrania.
* Jako użytkownik chcę zaakceptować rekomendowane ubrania.
* Jako użytkownik chcę odrzucić wybrane rekomendacje.

### Task 3.6 – Optymalizacja liczby ubrań

#### User Stories

* Jako użytkownik chcę zabrać jak najmniej ubrań.
* Jako użytkownik chcę otrzymać jak najwięcej stylizacji z minimalnej liczby ubrań.
* Jako użytkownik chcę zobaczyć, dlaczego dane ubranie zostało wybrane.

### Task 3.7 – Dobór uniwersalnych elementów garderoby

#### User Stories

* Jako użytkownik chcę otrzymać najbardziej uniwersalne ubrania.
* Jako użytkownik chcę zobaczyć, z iloma stylizacjami można połączyć dane ubranie.

### Task 3.8 – Prezentacja rekomendowanej garderoby

#### User Stories

* Jako użytkownik chcę zobaczyć rekomendowaną garderobę.
* Jako użytkownik chcę sprawdzić liczbę proponowanych ubrań.

### Task 3.9 – Akceptacja lub modyfikacja rekomendacji

#### User Stories

* Jako użytkownik chcę zaakceptować rekomendacje.
* Jako użytkownik chcę zmodyfikować rekomendacje.
* Jako użytkownik chcę, aby moje zmiany zostały uwzględnione w aktualnym zestawie rekomendacji.
* Jako użytkownik chcę, aby zaakceptowane przeze mnie zmiany w garderobie zostały uwzględnione podczas generowania stylizacji.

## Epic 4 – Generowanie stylizacji

### Task 4.1 – Tworzenie stylizacji na każdy dzień

#### User Stories

* Jako użytkownik chcę otrzymać stylizację na każdy dzień podróży.
* Jako użytkownik chcę otrzymać stylizację dopasowaną do planowanych aktywności.

### Task 4.2 – Wizualizacja stylizacji

#### User Stories

* Jako użytkownik chcę zobaczyć wizualizację każdej stylizacji.
* Jako użytkownik chcę zobaczyć wykorzystane ubrania.

### Task 4.3 – Dopasowanie stylizacji do pogody

#### User Stories

* Jako użytkownik chcę otrzymać stylizacje dopasowane do pogody.

### Task 4.4 – Dopasowanie stylizacji do aktywności

#### User Stories

* Jako użytkownik chcę otrzymać stylizacje dopasowane do aktywności.

### Task 4.5 – Zatwierdzenie i zmiana stylizacji

#### User Stories

* Jako użytkownik chcę zaakceptować wybrane stylizacje.
* Jako użytkownik chcę odrzucić stylizację, która mi nie odpowiada.
* Jako użytkownik chcę otrzymać alternatywną propozycję stylizacji dla wybranego dnia.
* Jako użytkownik chcę, aby zmiana stylizacji dla jednego dnia nie powodowała zmiany zaakceptowanych stylizacji dla pozostałych dni.
